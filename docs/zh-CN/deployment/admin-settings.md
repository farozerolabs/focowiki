# Admin 配置

在 Admin UI 的知识库页面打开**设置**。保存后的值会在服务重启后继续保留。修改会应用到新请求和新启动的任务；已经运行的任务可能继续使用启动时的值直至完成。

以下内容与当前设置页实际显示的字段一致。建议从默认值开始，确认 CPU、内存、PostgreSQL、Meilisearch 和 S3 延迟后再提高并发。

## API 限流

| 设置 | 用途 | 默认值 |
| --- | --- | --- |
| 管理员登录 / 最大请求数 | 一个窗口内允许的登录尝试次数。 | `8` |
| 管理员登录 / 窗口秒数 | 登录计数窗口长度。 | `900` |
| Admin API / 最大请求数 | 一个窗口内允许的 Admin UI API 请求次数。 | `600` |
| Admin API / 窗口秒数 | Admin API 计数窗口长度。 | `60` |
| Developer OpenAPI / 最大请求数 | 一个窗口内允许的 Developer OpenAPI 请求次数。 | `1200` |
| Developer OpenAPI / 窗口秒数 | Developer OpenAPI 计数窗口长度。 | `60` |

这些限制在 Focowiki 内生效。反向代理或边缘服务应配置相互匹配的限流规则。

## Worker

| 设置 | 用途 | 默认值或初始值 |
| --- | --- | --- |
| 来源文件并发 | 同时处理的文件数量。 | `2`；测量后逐步增加，最大 `32`。 |
| 来源文件读取并发 | 同时从存储读取的上传 Markdown 文件数量。 | `2`；不能高于来源文件并发。 |
| 每轮领取文件数 | 每次检查队列时选择的文件数量。 | `10`；不能低于来源文件并发。 |
| 轮询间隔毫秒 | 两次队列检查之间的等待时间。 | `1000` |
| 处理锁秒数 | 中断的文件处理可以重新开始前的等待时间。 | `900` |
| 心跳间隔毫秒 | 运行中的任务报告仍在工作的间隔。 | `15000` |
| 处理最大尝试次数 | 文件保持失败状态前允许的尝试次数。 | `3` |
| 处理重试延迟毫秒 | 临时失败后再次尝试前的等待时间。 | `30000` |
| 完成记录保留天数 | 已完成处理记录的保留天数。 | `7` |
| 清理并发 | 同时执行的文件删除清理任务数。 | `1` |
| 清理数据库批次大小 | 单个清理批次处理的数据库记录数。 | `1000` |
| 清理存储批次大小 | 单次清理请求处理的存储文件数。 | `1000`，最大 `1000`。 |
| 清理最大尝试次数 | 单个清理任务允许的尝试次数。 | `3` |
| 清理重试延迟毫秒 | 临时清理失败后再次尝试前的等待时间。 | `60000` |

大批量导入期间 CPU、数据库延迟或存储延迟上升时，优先降低来源文件并发和来源文件读取并发。

## 发布

| 设置 | 用途 | 默认值或初始值 |
| --- | --- | --- |
| 模式 | `batch` 合并多次更新，`per_file` 让单个完成文件尽快可见，`manual` 等待手动发布。 | `batch` |
| 间隔秒数 | 两次批量发布检查之间的最长等待时间。 | `300` |
| 发布并发 | 同时处理的发布任务数。 | `1` |
| 每轮领取任务数 | 每次检查队列时选择的发布任务数。 | `1`；不能低于发布并发。 |
| 生成文件写入并发 | 同时写入存储的生成文件数。 | `8`；最大 `32`。 |
| 目录单页条目数 | 单个生成目录页直接列出的条目数，不限制目录内文件总数。 | `200` |
| 目录单页字节数 | 单个生成目录页允许的最大 UTF-8 字节数。 | `65536` |

大批量导入使用 `batch`，关注快速可见时使用 `per_file`，需要明确控制发布时间时使用 `manual`。

## 图关系

| 设置 | 用途 | 默认值 |
| --- | --- | --- |
| 候选文件上限 | 为单个文件发现关系时考虑的文件数量。 | `200` |
| 接受关系上限 | 每个文件保留的关系数量。 | `50` |
| 默认搜索深度 | API 请求未提供深度时使用的关系层数。 | `1` |
| 最大搜索深度 | API 接受的最高关系层数。 | `2` |
| 默认搜索扇出 | 请求未提供时，每一步继续探索的相关文件数。 | `10` |
| 最大搜索扇出 | API 接受的最高扇出。 | `25` |
| 模型关系复核 | 允许当前生效模型复核关系建议。 | 开启 |
| 通用短语阈值 | 忽略过于宽泛的共享短语时使用的最小标准化长度。 | `4` |

默认深度和扇出不能高于各自最大值。模型复核为可选能力；没有生效模型时，关系发现仍会继续。

## 维护

| 设置 | 用途 | 默认值或初始值 |
| --- | --- | --- |
| 知识库维护模式 | `manual` 只在手动请求时运行；`automatic` 还会按计划检查。 | `manual` |
| 自动维护间隔秒数 | 自动模式下两次计划检查之间的时间。 | `21600` |
| 知识库维护并发 | 同时维护的知识库数量。 | `1`；最大 `16`。 |
| 存储一致性检查 | 定期查找可以安全清理的存储条目。 | 开启 |
| 存储扫描批次大小 | 单个批次检查的存储条目数。 | `500`；最大 `1000`。 |
| 存储删除批次大小 | 单个批次删除的已确认无用条目数。 | `100`；最大 `1000`。 |
| 存储清理宽限秒数 | 无用条目允许删除前至少保留的时间。 | `86400` |
| 存储清理最大尝试次数 | 单个清理操作允许的尝试次数。 | `5` |
| 存储清理重试延迟毫秒 | 临时清理失败后的等待时间。 | `30000` |
| 生成内容修复并发 | 同时处理的生成内容修复任务数。 | `4`；最大 `16`。 |
| 生成内容修复数据库批次大小 | 单个修复批次处理的记录数。 | `2000`；范围 `100` 到 `10000`。 |
| 生成内容修复存储写入并发 | 同时写入存储的修复文件数。 | `4`；最大 `32`。 |
| 搜索重建并发 | 同时处理的搜索重建任务数。 | `4`；最大 `16`。 |
| 搜索重建来源读取并发 | 重建期间同时读取的来源 Markdown 文件数。 | `2`；最大 `32`。 |
| 搜索重建内存上限字节 | 重建读取期间最多保留的来源 Markdown 字节数。 | `67108864`；范围 1 MiB 到 512 MiB。 |

在知识库页面使用**维护索引**，可以修复当前知识库的导航、搜索、关系和生成内容。维护期间，已经可以读取的文件继续可用。状态区域会展示进度、重试、最近活动和需要处理的失败。

## 搜索

| 设置 | 用途 | 默认值 |
| --- | --- | --- |
| 搜索请求超时毫秒 | 单次搜索请求允许的总时间。 | `3000` |
| 搜索服务超时毫秒 | 单次搜索服务请求允许的时间，必须低于总超时。 | `1000` |
| 结果补取倍数 | 返回页面前移除不可用文件时额外请求结果的倍数。 | `3` |
| 索引更新文档数 | 单次搜索更新最多提交的文档数。 | `10000` |
| 索引更新压缩字节数 | 单次搜索更新允许的最大压缩大小。 | `8388608` |
| 在途搜索任务数 | 同时等待完成的搜索更新任务数。 | `8` |
| 搜索任务轮询间隔毫秒 | 两次任务状态检查之间的等待时间。 | `500` |
| 搜索任务超时毫秒 | 单次搜索更新进入重试处理前允许的最长时间。 | `600000` |
| 搜索任务最大尝试次数 | 搜索更新或清理操作允许的尝试次数。 | `5` |
| 搜索重试延迟毫秒 | 临时搜索失败后再次尝试前的等待时间。 | `2000` |
| 搜索清理批次大小 | 单个清理批次删除的旧搜索记录数。 | `1000` |
| 未完成索引保留小时数 | 失败或被替换的索引在清理前保留的时间。 | `24` |
| 搜索结果摘要长度 | 每条搜索结果请求的最大摘要字符数。 | `1200` |

搜索服务超时必须低于总请求超时。Meilisearch 内存或磁盘延迟上升时，降低单次更新大小或在途任务数。

## 模型

模型辅助为可选能力。没有生效模型时，文件处理、导航、搜索和关系功能仍会继续。同一时间只能有一个生效模型。

| 设置 | 用途 | 推荐值 |
| --- | --- | --- |
| 显示名称 | Admin UI 中显示的名称。 | 包含服务商和用途。 |
| API 模式 | 服务商使用的协议。 | `responses` 或 `chat_completions`，与服务商一致。 |
| Base URL | OpenAI 兼容 API 地址。 | 服务商要求时包含 `/v1`。 |
| API key | 后端使用的服务商凭据。 | 使用独立 key 并定期轮换。 |
| 模型名称 | 服务商模型标识。 | 与服务商文档完全一致。 |
| 上下文窗口 tokens | 模型上下文容量。 | 使用服务商公布的上限。 |
| 请求最大超时毫秒 | 单次模型请求允许的总时间。 | 长文件使用 `600000` 或更高。 |
| 请求空闲超时毫秒 | 模型响应没有活动时允许的最长等待时间。 | `120000` 到 `300000`。 |
| 建议生成并发 | 同时执行的模型请求数。 | 从 `1` 或 `2` 开始。 |
| 临时错误重试延迟毫秒 | 服务商临时失败后再次尝试前的等待时间。 | `60000` |
| 请求最小间隔毫秒 | 两次模型请求之间的最小等待时间。 | 稳定服务使用 `0`，严格限流时适当增加。 |

模型创建后不会再次显示完整 API key。暂停模型后，新任务不会再选择该模型。运行中的任务仍在使用模型时，需要等待任务完成后再删除。

## 配置生效

Admin 配置由 Focowiki 保存，不应写入 `.env`。端口、域名、基础设施凭据、数据库连接上限、存储凭据和日志路径仍属于启动配置。修改启动配置后需要重启对应服务。
