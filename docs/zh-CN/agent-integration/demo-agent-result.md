# 演示运行测试结果示例

这个示例展示第三方 Agent 通过 Focowiki 演示服务读取法律知识库，并基于知识库内容回答问题。

演示服务把 Focowiki OpenAPI 密钥保存在后端。Skill 通过 HTTP 请求访问演示服务，搜索已配置的知识库，读取命中的文件，并基于读取到的证据生成回答。

## 如何理解这个示例

这段录屏使用法律文档作为测试数据，展示一条基于文件证据的读取流程。它不构成通用准确率对比，也不表示知识库只能用于法律领域。

Agent 先使用完整问题搜索，把返回文件视为候选，再读取有价值的 Markdown 原文；只有证据仍不完整时，才继续读取相关文件。最终回答引用实际读取过的文件。搜索摘要和关系说明只帮助发现文件，不能单独作为回答证据。

同一流程也适用于产品文档、操作手册、研究记录、政策、客服资料和其他 Markdown 集合。最终回答质量仍取决于上传内容、用户问题、所选模型和 Agent 的探索范围。

## 这个示例说明什么

- Skill 可以引导 Agent 在回答前先查询配置好的知识库。
- 演示服务可以为第三方 Agent 客户端提供一个小型只读 HTTP 接口。
- Agent 可以从搜索结果继续读取文件，并基于证据生成回答。
- 录屏中的法律文件只是测试数据，接入方案仍然面向通用知识库。
